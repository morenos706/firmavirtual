# Identidad visual — Manual de Marca Prebel

FirmaQR aplica el **Brandbook Prebel v1 (marzo 2025)** entregado por la empresa.

| Elemento del manual | Aplicación en FirmaQR |
|---|---|
| **Azul Prebel** `#40637D` (Pantone 7699C), color emblemático | Color primario: menú lateral, botones, títulos, encabezado del comprobante, informe, cartel QR y correos |
| **Gris Prebel** `#55606B` (Pantone 431C) | Textos y elementos sobrios |
| **Blanco Prebel** `#E3DED8` (Warm Gray 1C) y sus tintes | Fondos (`#F4F2EF`), texto sobre azul, elemento activo del menú |
| Colores secundarios `#5E8AB4` `#8DC8E8` `#5C7F71` `#6FA287` `#FF8674` | Estados (programado, firmado/entregado, pendiente), progreso del formulario |
| **Barra de color** (Secundario 1, 4, 2, 3, 5), solo decorativa | Parte superior del menú, inicio de sesión, formulario público, verificación, comprobante PDF, informe PDF, cartel QR y correos |
| Logotipo horizontal, versión preferente **Azul Prebel** | Planilla oficial, comprobante, cartel QR, informe, formulario público y panel (logo configurable por defecto) |
| Versión **Blanco Prebel sobre fondo Azul Prebel** | Pantalla de inicio de sesión |
| Zona de protección y reducción mínima (digital ≥ 150 px) | El logo se muestra sobre fondo limpio, sin efectos, sin deformar ni recolorear |
| Tipografía corporativa Acid Grotesk (licencia comercial) | No se incluye por licencia; puede cargarse si la empresa la provee |
| Tipografía complementaria **Work Sans** | Interfaz web (auto-alojada, `@fontsource/work-sans`) |
| Tipografía sustituta **Arial** | Documentos PDF (Liberation Sans, métricamente idéntica a Arial) — coincide además con el formato institucional |

El logotipo se obtuvo del manual en formato vectorial y se rasterizó en alta resolución con fondo transparente (`assets/brand/prebel-logo-azul.png`, `public/brand/`). No se alteraron formas, proporciones ni colores. La carga inicial (`npm run db:seed`) lo configura como logo institucional; puede reemplazarse en **Configuración → Logo institucional**.

> La **planilla oficial** conserva la presentación en blanco y negro del formato 11020001F-01 V0.6; de la marca solo incorpora el logotipo en el encabezado, como el documento de referencia.
